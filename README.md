# TechQuest — индустриальный мод с квестами (NeoForge 1.21.1)

Версии: Minecraft 1.21.1 · NeoForge 21.1.259 · Java 21 · ModDevGradle 2.0.148 · Gradle 9.4.1

## Что есть сейчас (этап 1)
- Оловянная руда (+ глубинная), генерация в мире, сырое олово, оловянный и бронзовый слитки
- Корпус машины
- **Угольный генератор**: GUI, слот топлива, шкала энергии, выдача FE соседним блокам
- Базовый класс `MachineEnergyStorage` для всех будущих машин
- Русский и английский языки, рецепты, лут, теги `c:`
- GitHub Actions: автосборка `.jar` при каждом push

## Как собрать без IntelliJ (GitHub + Codespaces)
1. Создай пустой репозиторий на github.com.
2. Открой его в Codespaces: зелёная кнопка **Code → Codespaces → Create codespace**.
3. Перетащи `techquest-stage1.zip` в панель файлов слева.
4. В терминале Codespaces:
   ```
   unzip -o techquest-stage1.zip && rm techquest-stage1.zip
   git add -A && git commit -m "TechQuest stage 1" && git push
   ```
5. Вкладка **Actions** → последний запуск → внизу **Artifacts → techquest-jar**.
6. Если сборка красная — открой лог, скопируй ошибку и пришли её сюда.

## Как проверить мод в игре
1. Установи NeoForge 21.1.259 (или новее для 1.21.1).
2. Положи `techquest-0.1.0.jar` в папку `mods`.
3. Создай мир, вкладка творчества **TechQuest**. Руда генерируется на высоте Y -40…56.

## Путь прогрессии
Оловянная руда → плавка → слиток олова; 3 медных слитка + 1 оловянный → 4 бронзы;
бронза + железо → корпус; бронза + корпус + печь + редстоун → угольный генератор.

## Структура
```
com.techquest
├─ TechQuest.java          точка входа
├─ registry/               блоки, предметы, BE, меню, вкладка
├─ block/ block/entity/    логика блоков и машин
├─ menu/                   серверная часть GUI
├─ client/                 экраны (только клиент)
└─ energy/                 общее хранилище FE
```
